# Room Booking Requirements

## Project Purpose

The Room Booking application aims to help users reserve rooms and manage their bookings.

## Proposed Features

- Select a room.
- Select a booking date and time.
- Create a reservation.
- Display existing reservations.
- Cancel a reservation.

## Booking Rules

- All required fields must be completed.
- The end time must be after the start time.
- A room cannot have overlapping reservations.
- Personal data must not be stored in the public repository.

## Expected Result

Users should be able to create and manage room reservations through a simple web interface.
