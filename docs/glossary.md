# Glossary

Words we use in our Room Booking app.

 Room: a place that can be booked
 Booking: one reservation of a room for a date and a time. 
 Time slot: the start and end time of a booking, for example 10:00–12:00.
 Booked by: the group that made the booking. We use group names,
  not real names, because our repository is public.
 Double booking: two bookings for the same room at the same time.
  The app should prevent this.
 Capacity: how many people fit in a room.
